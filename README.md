# Sam Lassiter | Professional Portfolio

A responsive, free, static portfolio website built for GitHub Pages. No paid website builder, frameworks, build tools, or hosting fees are needed.

## Before publishing

Open `index.html` in a text editor and update the following **sample content** with your own information:

1. **Hero introduction:** Describe your professional interests and career goals.
2. **About:** Replace the placeholder general biography with an accurate one.
3. **Experience:** Replace the two sample positions with actual roles, organizations, dates, and accomplishments.
4. **Education:** Fill in your actual degree, college, and graduation date.
5. **Selected work:** Replace the three placeholder projects and generic descriptions with real examples. The geometric illustrations are temporary and can be replaced with your own photos or project screenshots.
6. **Skills:** Keep only skills you can confidently demonstrate.
7. **Contact:** Replace `YOUR_EMAIL@example.com` and `https://www.linkedin.com/` with your actual links.

Never post a private phone number, home address, passwords, or confidential employer documents in a public repository.

## Publish through GitHub Pages

1. Log into the GitHub account `Samlassiter`.
2. Create a new **public** repository called `Samlassiter.github.io` (GitHub names are case insensitive, and the displayed URL will typically be lowercase).
3. Click **Add file → Upload files** on the repository's **Code** tab. Extract the ZIP first and upload `index.html`, `style.css`, `script.js`, `favicon.svg`, `README.md`, and `.nojekyll` **directly into the repository root**. Do not upload the enclosing `samlassiter-portfolio` folder.
4. Commit the files to the default `main` branch.
5. Go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**. Select `main` and `/(root)`, then **Save**.
6. Visit `https://samlassiter.github.io` once the deployment completes. GitHub says publication can take up to 10 minutes.

## Edit later

For quick edits, open `index.html` in GitHub and click the pencil icon. Use `style.css` to adjust layout, colors, and typography. Every commit to `main` triggers an updated GitHub Pages deployment.

## Files

- `index.html`: all website content
- `style.css`: responsive design
- `script.js`: mobile menu and dynamic copyright year
- `favicon.svg`: browser tab icon
- `.nojekyll`: lets GitHub Pages serve the static files directly

You may use this starter for your own portfolio.
